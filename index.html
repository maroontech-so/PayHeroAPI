Usage Instructions

Use the generated API Key in your applications via the x-api-key header.

Initiate STK Push:

POST /api/pay/stk-push
Headers: { "x-api-key": "YOUR_KEY", "Content-Type": "application/json" }
Body: {
  "phone_number": "254712345678",
  "amount": 100,
  "external_reference": "order_001",
  "callback_url": "https://your-app.com/callback" (optional)
}

Query Transaction:

GET /api/pay/status/order_001
Headers: { "x-api-key": "YOUR_KEY" }
